Memory, Know Your PLACE:Governing Lifecycle State and Query-Time Eligibility in Persistent-Memory Agents

Chen-Fang Hu1, Hong-Han Shuai2,*, Woan-Shiuan Chien2,*

1Arête Honors Program  ·  2Institute of Electrical and Computer Engineering
National Yang Ming Chiao Tung University, Taiwan

*Corresponding authors

Paper GitHub Code Citation

TL;DR

An agent can remember an outdated fact or let information that is no longer eligible shape its answer. PLACE governs both problems by separating state correctness from influence correctness. Across two model scales, PLACE maintains StateCorrectness of 1.000, reduces measured causal LeakageRate to 0.000 in the state correct comparison, and achieves the highest JointSuccess.

Abstract

Persistent memory turns prior interactions into durable agent state, but existing systems provide limited control over whether that state remains valid and whether it should influence a later query. We argue that reliable memory requires governance over both state formation and query-time influence. We introduce PLACE, a factorized governance layer that adds write-side state certification and read-side authorization to a memory backend. A factorial evaluation on Mem0 with Qwen2.5-3B and Qwen2.5-7B isolates the contribution of each mechanism. Results show that write-side governance substantially improves lifecycle state correctness, while read-side governance eliminates measured causal leakage from ineligible memory in the state-correct setting. Their combination achieves the strongest joint performance while preserving query-relevant support. These findings show that reliable persistent memory requires explicit control over both maintained state and query-time information influence.

Key Contributions

  • Distinguish valid memory from permissible influence. A memory agent may preserve outdated facts or use stored information outside the scope of a query. We separate state correctness from influence correctness so these failures can be measured and addressed independently.
  • Certify the state that is actually stored. CSS applies trusted user events, realizes the resulting state in persistent storage, and verifies physical readback. It increases longitudinal StateCorrectness from 0.488 to 1.000 at 7B and from 0.414 to 1.000 at 3B.
  • Authorize memory before it can shape an answer. QASC exposes only query eligible support backed by physical memory. With the stored state correct, measured causal LeakageRate falls from 0.125 to 0.000 at 7B and from 0.083 to 0.000 at 3B, while PLACE preserves all measured query needed support in the Utility diagnostic.
  • Verify the benefit of combining both controls. The factorial design separates write errors from read errors. Their combination, PLACE, achieves the highest strict JointSuccess, 0.667 at 7B and 0.625 at 3B, without assuming that a correct final answer proves correct memory governance.

Framework

PLACE places two controls around an existing memory backend. CSS governs how current facts are stored. QASC governs which of those facts may reach the answer model for a given query. Neither requires replacing the memory backend or the answer model.

In the example, a flight departure changes from 9:00 to 11:00. CSS records and verifies 11:00 as the current departure. QASC permits the current time and its provenance while excluding the superseded value from the answer context.

Main Findings

Finding 01 · Writing governance

Governing writes restores correct memory state

The governed writer improves StateCorrectness from 0.488 to 1.000 for Qwen2.5 7B and from 0.414 to 1.000 for 3B. Native and QASC use the same Native state producer; CSS and PLACE use the same governed producer. The result isolates the benefit of controlling state formation instead of relying on retrieval to compensate for incorrect memory.

Finding 06 · Automatic parsing

Automatic semantic interpretation remains a bottleneck

The Primary study uses trusted event and query semantics to isolate governance. A separate parser diagnostic shows why automated interpretation remains difficult. When parsed events replace trusted events, support correctness falls substantially, even where the overall state F1 stays close to 1.000. These results should not be interpreted as performance of the controlled Primary configuration.

Finding 07 · Auxiliary validation

Answer similarity and support use reveal residual limitations

A separate evaluation of recorded responses compares conventional answer similarity with factual value accuracy and required support use. PLACE performs strongly on lexical and factual checks, but visible support does not always transfer into the final answer. These measures complement the governance endpoints rather than replacing semantic AnswerCorrectness or JointSuccess.

Conclusion

The results highlight a fundamental distinction in persistent memory: maintaining the correct state does not guarantee that memory will influence future responses appropriately. PLACE addresses these requirements separately through CSS and QASC. Their combination achieves the strongest joint governance performance in our controlled evaluation, while the parser diagnostics identify automatic semantic interpretation as an important direction for future work.
